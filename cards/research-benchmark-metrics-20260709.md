# Historical ZeroThink/OpenZero software benchmark measurements

Author: Shafaet Brady Hussain. Published 23 October 2026. Measurement date:
9 July 2026. Original author-owned data: CC BY 4.0.

The four CSVs contain 213 historical diagnostic measurements: 130 OpenZero model
API checks, 50 ZeroThink model checks, a separate ten-check follow-up, and 23
ZeroThink system checks. Run identity is retained by filename; a follow-up is
not an additional independent benchmark cohort.

The export retains selected categorical/numeric fields only. Account fields,
URLs, endpoint configuration, raw responses, generated answers, error bodies,
target paths and operator details are omitted. Source-file hashes identify the
local measurement inputs without publishing their contents. Each output has its
own SHA-256 and schema in MANIFEST.json.

These are small author-run diagnostics, not an independent model leaderboard or
general intelligence assessment. No new model/API benchmark was run for this
publication. A correct flag refers only to that harness's check; secret_hits is a
pattern-check count, not proof of confidentiality. Failures and measured latency
remain in the records. Hardware/load, provider/model availability, task overlap
with training and run-to-run variance limit comparisons.

No provider account, client dataset, private DNA, service response body or API key
is supplied. The source and resulting exported fields were reviewed separately;
pattern scanning alone is not a privacy guarantee.
